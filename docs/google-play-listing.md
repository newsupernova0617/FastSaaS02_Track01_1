## 4. 스토어 등록에서 제가 넣기 어려운 항목

아래 항목은 실제 이미지 또는 동영상 파일이 필요해서, 지금은 제가 텍스트만 준비할 수 있습니다.

- 앱 아이콘
  - 필요 규격: PNG 또는 JPEG, 512 x 512px, 1MB 이하
- 그래픽 이미지
  - 필요 규격: PNG 또는 JPEG, 1024 x 500px, 15MB 이하
- 휴대전화 스크린샷
  - 2~8장 필요
  - 가능하면 1080px 이상 권장
  - 권장 캡처 화면:
    - 홈 화면
    - 거래 추가/수정 화면
    - 캘린더 화면
    - 통계 화면
    - AI 채팅 화면
    - 설정 화면
- 7인치 / 10인치 태블릿 스크린샷
  - 태블릿 지원을 실제로 제출할 때만 필요
- Chromebook 스크린샷
  - Chromebook 지원을 제출할 때만 필요
- Android XR 스크린샷 / 동영상
  - XR을 지원하지 않으면 보통 제출하지 않습니다
- 홍보 동영상
  - YouTube 공개 또는 일부 공개 링크가 필요합니다
