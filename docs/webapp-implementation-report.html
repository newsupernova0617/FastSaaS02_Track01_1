3. 작업 요약

  • 새로운 webapp/ 패키지를 만들고 PWA 셸을 구성했습니다.
  • vite + hono/jsx/dom + Navigo + @tanstack/query-core + zustand/vanilla + zod 조합을 넣었습니다.
  • 랜딩페이지 mock UI와 같은 톤으로 홈, 리포트, AI 검색 화면을 구현했습니다.
  • 실제 Flutter 전체 기능 이식이 아니라, 먼저 동작하는 웹앱 베이스와 preview 데이터 연결까지 만든 상태입니다.
