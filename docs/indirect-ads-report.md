### 2. `how-to-analyze-spending-patterns.mdx`

- **필요 사진**: AI 리포트 화면 (차트 + 텍스트 인사이트)

### 3. `budget-for-living-alone.mdx`
- **위치**: "앱으로 관리하면 더 쉬운 경우" 설명 바로 아래
- **강조**: Android 알림 빠른 입력, AI 자동분류, 자취 맞춤 카테고리
- **필요 사진**: Android 알림창 빠른 입력 모습

### 4. `why-people-quit-household-book.mdx`
- **위치**: "방식이 안 맞으면 바꾸는 게 맞다" ProductFlow + Callout 아래
- **강조**: 채팅 3초 입력, 알림 빠른 입력, 취소(undo) 기능
- **필요 사진**: AI 채팅 입력 화면 (한국어 자연어 → AI 응답)

- **위치**: "가계부와 예산을 같이 붙여야 하는 이유" 본문 아래

## 랜딩페이지 mock 대체용 사진

현재 랜딩페이지에는 실제 이미지 대신 아래 목업이 들어가 있다.

- `frontend/src/components/ChatDemo.astro`
- `frontend/src/components/Screenshots.astro`

실제 제품 사진으로 교체하려면, 블로그용 사진과 별도로 랜딩 구조에 맞는 대표 화면을 준비해야 한다.

### 1. 히어로 대표 화면
- **대체 대상**: `ChatDemo.astro`
- **역할**: 랜딩 첫 화면에서 "말로 기록하고 바로 저장된다"는 인상을 한 장으로 보여주는 대표 이미지
- **필요 사진**: AI 채팅 기록 화면
- **꼭 보여야 하는 요소**
  - 사용자가 자연어로 지출 입력한 말풍선
  - AI가 "기록했어요"처럼 즉시 응답한 말풍선
  - 자동 분류된 지출 카드 1개
  - 하단 입력창 또는 질문 입력 영역
- **추천 예시**
  - "어제 점심 12000원 썼어" 입력
  - AI 응답
  - 식비로 분류된 기록 카드

### 2. 랜딩 미리보기 1번 화면
- **대체 대상**: `Screenshots.astro` 의 "대화로 기록"
- **역할**: 한 줄 입력으로 기록이 끝난다는 점 강조
- **필요 사진**: 홈 또는 채팅 기록 화면
- **꼭 보여야 하는 요소**
  - 최근 대화 1~2개
  - 저장 완료 상태
  - 최근 지출 카드 또는 오늘 기록 요약

### 3. 랜딩 미리보기 2번 화면
- **대체 대상**: `Screenshots.astro` 의 "월별 리포트"
- **역할**: AI가 지출을 분석해서 요약해준다는 점 강조
- **필요 사진**: AI 리포트 또는 통계 화면
- **꼭 보여야 하는 요소**
  - 월간 총지출
  - 카테고리 차트 또는 막대 그래프
  - 한 줄 인사이트 텍스트
- **추천 예시**
  - "지난달보다 12,400원 증가"
  - 식비/교통/카페 등 상위 카테고리

### 4. 랜딩 미리보기 3번 화면
- **대체 대상**: `Screenshots.astro` 의 "AI 검색"
- **역할**: 사용자가 묻고 바로 소비 내역을 찾을 수 있다는 점 강조
- **필요 사진**: 검색 또는 AI 질의응답 화면
- **꼭 보여야 하는 요소**
  - 질문 문장 1개
  - 기간 요약 결과
  - 카테고리별 또는 항목별 응답 결과
- **추천 예시**
  - "지난주 식비 얼마였어?"
  - 총액, 하루 평균, 세부 항목

## 촬영할 때 맞춰둘 원칙

- 한 세트 안에서는 Android 또는 iPhone 중 하나로 통일
- 테스트용 더미 데이터는 실제 사용 흐름처럼 자연스럽게 구성
- 이름, 이메일, 카드번호, 실제 알림 내용 같은 개인정보는 제거
- 시간, 배터리, 통신 상태가 너무 어색하지 않게 정리
- 지출 금액과 카테고리는 반복 노출돼도 이해되는 수준으로 단순화
- 너무 빈 화면보다 "입력 → 저장 → 결과"가 보이는 상태를 우선 촬영

이 문서 기준으로 사진을 준비하면 블로그 `AppShowcase` 와 랜딩페이지 mock 대체 작업을 같이 진행할 수 있다.
